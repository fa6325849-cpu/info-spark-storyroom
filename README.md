# Info Spark Storyroom

Act as a senior full-stack web developer, UI/UX designer, and professional news website developer.

Build a complete, modern, professional, responsive news and blogging website named "Info Spark's".

The website should look like a premium international news portal, similar in quality to BBC News, CNN, and other professional online news magazines.

1. Website Design and Branding

Website name: Info Spark's

Tagline: "Your World. Your News. Your Daily Update."

Design style: Modern, clean, elegant, professional, and trustworthy.

Color scheme: White background, dark navy blue, black text, and red accent color.

Fully responsive on desktop, tablets, and mobile phones.

Smooth animations and modern typography.

Professional logo with the text "Info Spark's".

2. Homepage

Create an attractive homepage containing:

Professional header with logo.

Navigation menu.

Breaking News ticker.

Large featured news section.

Latest news articles.

Trending news section.

Popular articles.

Editor's picks.

Category-based article sections.

Sidebar with trending posts and popular tags.

Newsletter subscription section.

Professional footer.

3. News Categories

Create the following categories:

World News

Pakistan News

Technology

Business

Sports

Entertainment

Health

Education

Science

Lifestyle

Travel

Each category should have its own page displaying relevant articles.

4. Article Pages

Every article must have:

Attractive article title.

Featured image.

Author name.

Publication date and time.

Article category.

Reading time.

Social media sharing buttons.

Table of contents for long articles.

Well-formatted article content.

Related articles.

Previous and next article navigation.

Comment section.

SEO-friendly URL structure.

5. Admin Dashboard and Content Management

Create a secure admin dashboard where the website owner can:

Add new articles.

Edit existing articles.

Delete articles.

Upload featured images.

Manage categories.

Add article titles and descriptions.

Write and format article content.

Save drafts.

Publish articles.

Schedule articles.

Manage comments.

View basic website statistics.

Do not expose admin controls to ordinary visitors.

6. Search and User Experience

Working search bar.

Search articles by title and keywords.

Category filtering.

Pagination or load-more functionality.

Mobile-friendly navigation menu.

Fast page loading.

Easy-to-use interface.

7. SEO Optimization

Implement:

SEO-friendly URLs.

Meta titles and descriptions.

Open Graph tags.

Twitter/X sharing metadata.

XML sitemap.

Robots.txt.

Canonical URLs.

Article structured data (NewsArticle schema).

Breadcrumb navigation.

Image alt text.

Semantic HTML.

8. Google AdSense Monetization

Prepare the website for Google AdSense approval and monetization.

Include suitable advertisement placement areas:

Header advertisement.

Homepage advertisement.

Sidebar advertisements.

In-article advertisements.

Footer advertisement.

Advertisement areas should not disturb the reading experience.

Also create these essential pages:

About Us

Contact Us

Privacy Policy

Terms and Conditions

Disclaimer

Editorial Policy

9. Social Media Integration

Add social sharing options for:

Facebook

WhatsApp

X (Twitter)

LinkedIn

Telegram

10. Technical Requirements

Build a fully functional website, not just a static design.

Use clean, organized, reusable code.

Use a modern frontend framework and a reliable backend/database if supported.

Implement authentication for the admin dashboard.

Protect admin routes.

Make all buttons, links, forms, and navigation functional.

Optimize images and performance.

Ensure accessibility and mobile responsiveness.

Do not use fake functionality or non-working buttons.

11. Sample Content

Add realistic sample news articles for demonstration purposes.

Clearly label sample articles as demonstration content. Do not present fabricated news as real breaking news.

12. Final Deliverables

Generate:

Complete website source code.

Professional homepage.

Individual article pages.

Category pages.

Admin dashboard.

Responsive mobile design.

SEO implementation.

Setup and deployment instructions.

Make the final website visually impressive, professional, fast, user-friendly, and suitable for a serious digital news publication.

Important: Prioritize a fully working website with a consistent design and functional features. Do not stop after creating a homepage mockup. Explain how to run and deploy the finished project.
